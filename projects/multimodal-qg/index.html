System · 02

Multimodal Question Generation Platform

MPhil Thesis HKU Faculty of Education 2025 – present

The problem

Teachers in bilingual programmes assess students across English and Chinese using text, images, and audio — but existing tools for writing test questions only handle one language and plain text. This platform generates multilingual, multimodal assessment items with an LLM and lets teachers review and edit them against their curriculum framework.

What I did

  • Designed and built the full-stack application in Next.js, deployed on Railway.
  • Integrated LLM APIs for curriculum-aware item generation.
  • Implemented multimodal input processing — text, image, and audio.
  • Piloting with 7 in-service teachers in Hong Kong secondary schools.

Evidence

  • Piloting with 7 in-service teachers in Hong Kong secondary schools.
  • Generates assessment items across text, image, and audio modalities.
  • Full-stack Next.js application deployed on Railway.
  • Informed by analysis of 956 public examination questions (HKDSE 2018–2023, Biology and Geography).
